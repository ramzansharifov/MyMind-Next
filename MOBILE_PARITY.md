## Architecture decisions

- Native React Native UI only. No renderer imports, DOM JSX, WebView-based desktop app, or mock records.
- `@mymind/contracts`: existing domain types and platform-neutral ports. Desktop source paths re-export shared definitions to keep IPC consumers stable.
- `@mymind/core`: existing Zod validation and pure rules. No SQL driver, Expo, Electron or application imports.
- `@mymind/persistence`: shared SQL repository factories, row mapping and atomic transactions. Added separately to avoid placing persistence implementation in domain core. The platform passes a database/UUID/clock runtime; no global mutable driver switch.
- Expo SQLite local database, foreign keys, WAL, versioned transactional migrations. Production database is never reset during initialization. Settings use the same database. No cloud backend.
- Porting a repository does not claim that every platform service or UI feature is complete. Native notifications, document assets and vault security require distinct adapters and runtime checks.

## Verification and continuation

Workouts checkpoint verified on 2026-09-06 with a clean lockfile install and the following local gates: `npm ci`; `npm run lint:mobile`; `npm run typecheck`; `npm run test:mobile` (8 files, 35 tests); `npm run test:run` (189 files, 715 tests); `npm run db:check`; `npm run build:bundle`; `npm run export:android`; `npm run build:win`; and `git diff --check`. `npm audit --audit-level=high` reports no high or critical vulnerabilities; the remaining findings are moderate transitive development-tool issues whose suggested forced fixes are breaking downgrades.

Nutrition checkpoint verified on 2026-09-06 with `npm run lint:mobile`, `npm run typecheck`, and `npm run test:mobile` (9 files, 41 tests), including a V5 data-preserving migration test, desktop/native Nutrition schema parity, milli rounding, historical snapshots, recipe constraints/cascades, global targets, water, reports, duplicate imports, and transactional rollback. The full clean-install/build matrix is rerun before the checkpoint commit.

Finance checkpoint verified on 2026-09-06 with shared/desktop/mobile typechecks, 57/57 mobile/shared tests, focused desktop Finance service tests, rich report parity (comparisons, balance timeline, account activity, converted transfer flows, limits), formatting, and `git diff --check`. The native Finance screen exposes the real local ledger and rich reports; no stored-balance shortcut or floating-point persistence is used.

Next implement Passwords with the audited desktop vault format: shared validation/contracts, additive encrypted mobile schema, scrypt parameter parity, AES-256-GCM with AAD, wrapped DEK lifecycle, secure clipboard TTL behavior, then the native vault UI. Plaintext persistence and dummy vault fallbacks are forbidden.
