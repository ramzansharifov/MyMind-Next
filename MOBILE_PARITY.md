## Architecture decisions

- Native React Native UI is the default and no desktop renderer is embedded. Boards are the deliberate exception: the canvas alone runs the exact tldraw web editor in Expo’s first-party offline DOM-component bridge so desktop tldraw snapshots remain lossless; the surrounding app, navigation and persistence stay native. No remote website or desktop app is wrapped, and no mock records are used.
- `@mymind/contracts`: existing domain types and platform-neutral ports. Desktop source paths re-export shared definitions to keep IPC consumers stable.
- `@mymind/core`: existing Zod validation and pure rules. No SQL driver, Expo, Electron or application imports.
- `@mymind/persistence`: shared SQL repository factories, row mapping and atomic transactions. Added separately to avoid placing persistence implementation in domain core. The platform passes a database/UUID/clock runtime; no global mutable driver switch.
- Expo SQLite local database, foreign keys, WAL, versioned transactional migrations. Production database is never reset during initialization. Settings use the same database. No cloud backend.
- Porting a repository does not claim that every platform service or UI feature is complete. Native notifications, document assets, PDF export and vault crypto use explicit platform adapters; tests/builds cover portable correctness, while permission/share/notification lifecycle behavior still requires physical-device smoke validation.
