# Проверка переноса MyMind в PWA

Дата аудита: 19 октября 2026. Android/iOS и desktop сохранены. PWA использует те же компоненты и репозитории через браузерные адаптеры. Удалённого хранилища данных нет.

## Результат автоматической проверки

- `test:pwa`: 140 из 140 тестов, 30 файлов.
- `test:e2e:pwa`: 63 из 63 запусков; 21 сценарий в каждой из трёх конфигураций Chrome desktop, Chrome phone и WebKit phone. Изображения и backup проверяются везде; тестовый микрофон и запись MediaRecorder — в Chrome.

  В полном прогоне прошёл 61 случай. После уточнения мобильного ввода форматирования и проверки переименования привычки оставшиеся два случая WebKit отдельно перепроверены успешно. WebKit с мобильной эмуляцией не применяет desktop-комбинацию выделения текста; сценарий проверяет форматирование при вводе через мобильную панель.

- Production-сборка, `typecheck:pwa`, `lint:pwa`, проверка форматирования PWA: успешно.
- `typecheck:mobile` и desktop `typecheck:web`: успешно.
- Локальный HTTPS: приложение и WASM — 200, разрешённый LAN-запрос — 200, запрос без обязательного заголовка — 403.

В ходе аудита исправлены перекрытие редактора заметок на телефоне, доступ к действиям задач и треков, передача состояний доступности из React Native Web, проверка файлов перед восстановлением, освобождение Blob URL, обновление фотографий после LAN и сохранение бинарных данных в WebKit. Совместимость чтения ранее записанных Blob сохранена.

## Соответствие интерфейсу Android

Общие MobileAppHeader и AppNavigationDrawer используются в Android и PWA; порядок основных разделов и карточки главной сохранены. Заметки используют NotesScreen и MobileNoteCanvas, а не отдельный desktop-интерфейс. В настройках восстановлены карточки разделов и мобильные кнопки темы и акцента. PWA сохраняет свои адаптеры хранения, установки, резервных копий и уведомлений.

Добавлены браузерные сценарии для меню, темы/акцента после перезапуска, Back внутри настроек и модальных панелей, форматирования заметки, сохранения при Back и работы панели инструментов при уменьшении высоты экрана. Высота виртуального листа не вытесняет панель инструментов за экран.

## Принятые ограничения и приёмка на устройствах

- По выбору пользователя внешний push отсутствует. Полностью закрытое PWA не обеспечивает таймеры нативного приложения; есть восстановление пропущенных уведомлений и экспорт в системный календарь.
- Данные привязаны к origin браузера. Перенос на другой адрес или телефон выполняется через копию либо LAN. Браузер не читает приватную базу установленного Android/iOS-приложения напрямую.
- Для установки и системных API на телефоне нужен HTTPS, которому телефон доверяет. Приложение не устанавливает сертификаты автоматически.
- Печать PDF, выбор файлов и воспроизведение выполняются браузером. Внешние видео, изображения и ссылки требуют сети.
- Chrome с сенсорной эмуляцией и WebKit на Windows проверяют браузерные сценарии, но не аппаратные особенности Android/iPhone. Нужны физическая установка, разрешения микрофона и уведомлений, фоновые переходы, LAN между устройствами и проверка пользовательской библиотеки её реального размера.

Нативные приложения остаются для сравнения и приёмки. Команды воспроизведения проверок приведены в [README.md](./README.md).
