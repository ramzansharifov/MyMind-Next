# Переход на Desktop и PWA

С 24 октября 2026 года поддерживаемые приложения — Desktop и PWA. Нативная оболочка Android/iOS, Expo/Metro, сборка APK, плагины и скрипты SDK исключены из рабочего дерева и npm workspaces. Предыдущие версии доступны в истории Git.

## Где находится перенесённый код

- `apps/pwa/src/client/app` — главная, навигация, меню, шапка, настройки, контекст и интерфейс сервисов.
- `apps/pwa/src/client/modules` — десять разделов телефонного интерфейса и их формы, отчёты и утилиты.
- `apps/pwa/src/client/shared/ui` — компоненты интерфейса, диалоги, редактор заметок и жесты.
- `apps/pwa/src/client/shared/backup` — прежний формат архива и интерфейсы результата; нативный файловый код не переносится.
- `apps/pwa/src/platform` — WebCrypto, clipboard, blur, React ref и настоящий MediaRecorder; обходные Expo-декларации и подмена нативного рекордера больше не нужны.
- `apps/pwa/src/storage` и `src/sync` — прежние реализации браузерного хранения, вложений, резервных копий, профиля и LAN.
- `apps/pwa/assets/icon.png` — собственный исходник установочных иконок, без изменения пикселей и публичных URL.
- `packages/*` — общие контракты, бизнес-логика, дизайн и persistence для Desktop и PWA.

Некоторые компоненты сохранили префикс `Mobile`: он описывает телефонный интерфейс, а не зависимость от нативного приложения. React Native Web и типы React Native остаются необходимыми для этой реализации интерфейса; Expo SDK приложению больше не требуется.

`apps/music-bridge` — вспомогательный локальный сервис музыки Desktop, а не третья пользовательская версия. Он сохраняется вместе с Desktop.

## Совместимость данных

Домен `https://mymind-pwa.vercel.app`, IndexedDB `mymind-pwa-v1`, stores `state`/`assets`, ключ SQLite, миграции, SQL-таблицы и формат `MYMIND01`/`.mymindbackup` сохранены. Исторические имена `mobile_preferences`, `mobileSchema*`, `MOBILE_SYNC_MODULES` и константы архива не переименовываются ради чистоты названий: это совместимость уже выпущенных данных и протокола Desktop/PWA.

Учёба, Доски и Тренировки остаются разделами Desktop. Их скрытые PWA-данные и вложения сохраняются в базе и резервных копиях. Удаление нативной оболочки не является миграцией пользовательской библиотеки.

Данные ранее установленного Android/iOS-приложения не появляются в браузере автоматически. Перед удалением приложения с телефона экспортируйте `.mymindbackup` и восстановите его через настройки PWA. Удаление исходников из репозитория само по себе не удаляет установленное приложение или его данные.

## Разработка и релизы

`npm ci` устанавливает только Desktop, PWA и общие пакеты. Android SDK, Java, Expo и Metro не нужны. Native-модуль `better-sqlite3` относится к Electron Desktop и сохраняется.

`npm run release:version -- <major.minor.patch>` обновляет Desktop и PWA вместе с lockfile. Ограничения Android versionCode удалены. GitHub Release публикует Windows updater и установщик без APK. PWA развёртывается Vercel из своего workspace.

`npm run typecheck` проверяет пакеты, Desktop и PWA. `npm run test:pwa` включает перенесённые тесты интерфейсной логики и общие persistence/core-тесты. Проверки релизного скрипта доступны как `npm run test:release`. CI также выполняет браузерные тесты PWA. Архитектурная регрессия проверяет отсутствие нативного workspace, Expo SDK в lockfile и импортов удалённого приложения.

Браузерные ограничения не изменились: локальные уведомления при полностью закрытой PWA недоступны, разрешения микрофона/clipboard и установка зависят от браузера. Установленная PWA на физическом Android/iPhone и перезапуск телефона требуют отдельной проверки на устройстве.

## Проверка перехода

Чистая установка зависимостей и production-сборка PWA выполнены без нативного workspace и Expo. Окончательный `npm install` также удалил 239 устаревших пакетов из локального node_modules. Декодер архива и исходная иконка побайтово совпадают с прежними файлами.

24 октября прошли 271 PWA/shared unit-тест в 58 файлах, в том числе на чисто установленных зависимостях, и 762 Desktop-теста в 197 файлах со всеми порогами V8 coverage. Проверены типы пакетов, Desktop и PWA, линтеры, форматирование, DB check, Desktop runtime bundle, PWA build и два теста release-version.

Браузерный набор содержит 51 сценарий в трёх конфигурациях: Chrome desktop, Chrome phone и WebKit phone. Два пропуска относятся к trusted CDP touch вне Chrome phone; проверка SW и сохранения данных остаётся включённой во всех конфигурациях. Итог полного CI и production-проверки фиксируется в PR перехода.

Проверки выявили и устранили гонки фокуса заметок: отложенный focus после команды мешал настройкам вложения, а освобождение focus trap после анимации могло прервать ввод. Редактор возвращает курсор по событию фактического закрытия окна, сохраняя форматирование. Музыкальный экран открывает локальную коллекцию офлайн без сетевого поиска и возобновляет его при подключении. Устаревшие музыкальные тесты main обновлены под текущий интерфейс и полный IPC-контракт; проверки совместимости и сохранения данных сохранены.
